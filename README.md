# パチパチ（pachipachi）

ハンドルの強さを調整して球を打ち出し、始動口への入賞から図柄変動や大当たりの演出を楽しむ、パチンコ風のブラウザゲームです。ネオン調の筐体で、球の流れ・保留・図柄・払い出しのつながりを観察できます。

## 遊び方

1. プレイヤー名を入力して遊技を始めます。名前は結果の共有文とランキングに使われます。
2. 発射強度のスライダーを調整し、ハンドル／「FIRE」を押し続けて球を発射します。離すと止まります。
3. 左打ちで始動口への入賞を狙います。入賞が保留され、順に図柄が変動します。
4. 大当たりや電チュー支援中は画面の案内に従って右打ちへ切り替え、アタッカーへの入賞を狙います。
5. 「PUSH」で結果ログを確認できます。下皿の球は上皿へ移せます。

球や払い出しはゲーム内の仮想BALLです。実機の攻略情報・出玉の保証ではありません。図柄の抽選結果は入賞時に決まり、PUSHや停止のタイミングで変更するゲームではありません。

## 結果と設定

- 結果スコア、上位10位のオンラインランキング、結果文・画像の共有入口があります。通信機能の実稼働は別途確認が必要です。
- 「SET」で演出強度と音量を調整できます。設定は端末内に保存されます。
- スマホでは画面下の操作部から発射・強度・左右の球道を選びます。

## 起動方法と公開状況

このREADMEでは動作確認済みの公開URLを案内していません。手元で試す場合は Node.js と package.json 指定の pnpm を用意します。

```sh
pnpm install
pnpm dev
```
